INVITACION PARA MARITA
======================

Contenido:
- index.html: sitio completo (HTML + CSS + JavaScript en un solo archivo)

Ver localmente:
1. Descomprime la carpeta si descargaste el ZIP.
2. Abre index.html en Chrome, Safari o Edge.

Publicar en Cloudflare Pages:
1. En Cloudflare ve a Workers & Pages > Create > Pages.
2. Elige Upload assets / Direct Upload.
3. Sube la carpeta invitacion-marita o el archivo ZIP descomprimido.
4. Asegurate de que index.html quede en la raiz del sitio.
5. Publica.

No usa backend ni base de datos. Solo carga Google Fonts; si no hay conexion,
usa tipografias de respaldo del dispositivo.
